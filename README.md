# Knowledge Graph in C

An in-memory knowledge graph and query engine implemented in C. The application loads entities and weighted relationships from CSV files, represents them as a directed graph, indexes entities by name, and processes graph queries from a FIFO queue.

## Highlights

- Directed, weighted graph represented with adjacency lists
- Dynamically allocated entities, graph nodes, edges, queues, and heap storage
- Binary Search Tree index for fast entity lookup by name
- Breadth-First Search for reachability and path reconstruction
- Dijkstra's algorithm with a custom binary min-heap for shortest paths
- Five supported query types: `EXISTS`, `EDGE`, `NEIGHBORS`, `PATH`, and `DIJKSTRA`

## Supported queries

| Query | Purpose | Main technique |
| :--- | :--- | :--- |
| `EXISTS <entity>` | Checks whether an entity exists | BST lookup |
| `EDGE <src> <dest>` | Checks for a direct relationship | BST lookup and adjacency-list scan |
| `NEIGHBORS <entity>` | Lists direct outgoing neighbors | Adjacency-list traversal |
| `PATH <src> <dest>` | Finds a path with the fewest edges | BFS and parent reconstruction |
| `DIJKSTRA <src> <dest>` | Finds a minimum-cost path | Dijkstra and binary min-heap |

## Data structures

| Component | Implementation | Role |
| :--- | :--- | :--- |
| **Graph** | Dynamic array of nodes with linked adjacency lists | Stores entities and directed weighted relationships |
| **Entity index** | Binary Search Tree | Locates graph nodes by entity name in `O(h)` |
| **Query queue**| Linked FIFO queue | Preserves query input order |
| **BFS queue** | Dynamic integer array | Traversing the graph level by level |
| **Dijkstra frontier**| Dynamic binary min-heap | Extracts the node with the lowest known distance in `O(log n)` |

## Compilation and Usage

**Prerequisites:**
- A C11-compatible compiler (GCC/MSYS2 recommended for Windows)
- GNU Make

**Compiling the project:**
Run the standard make command in the root directory:
```bash
make
```

**Running the engine:**
The executable expects three parameters: the entities file, the relationships file, and the queries file.
```bash
./build/knowledge_graph tests/public/pas4/entitati.csv tests/public/pas4/relatii.csv tests/public/pas4/interogari.txt
```

**Debug Mode:**
Appending `--debug` will print the internal adjacency lists and the BST inorder traversal to `stderr` without interfering with the standard query outputs.
```bash
./build/knowledge_graph <entities.csv> <relations.csv> <queries.txt> --debug
```

## Testing Pipeline

The project includes an automated test suite verifying edge cases and algorithm correctness. To run all stages:
```bash
make public-test
```
*Note: The project is compiled with strict flags (e.g., `-Wall`, `-Wextra`) to enforce memory safety and clean coding practices.*

## Algorithmic Complexity

*Where `V` is the number of vertices, `E` is the number of edges, `h` is the BST height, and `deg(x)` is the out-degree of node `x`.*

| Operation | Time Complexity | Auxiliary Space |
| :--- | :--- | :--- |
| `EXISTS x` | `O(h)` average | `O(1)` |
| `EDGE x y` | `O(h + deg(x))` average | `O(1)` |
| `NEIGHBORS x` | `O(h + deg(x))` | `O(1)` (excluding output print) |
| `PATH x y` | `O(V + E)` via BFS | `O(V)` (for queue and visited tracker) |
| `DIJKSTRA x y` | `O(E + V log V)` | `O(V)` (for distances, parents, and heap) |

*The priority queue (Min-Heap) maintains a logarithmic `O(log V)` insertion and extraction time, preventing the `O(V^2)` bottleneck typical of naive Dijkstra implementations.*

## Implementation Details

This project was developed as a core assignment for the Algorithms Design course at the National University of Science and Technology Politehnica Bucharest (UNSTPB). 

My specific technical contributions to the starter skeleton include:
- **Data Structures:** Engineered the custom Min-Heap (`src/heap.c`) and the generic linked FIFO Queue (`src/queue.c`).
- **Graph Logic:** Handled memory-safe dynamic allocations, adjacency list management, and edge insertions in `src/graph.c`.
- **Search & Pathfinding:** Implemented BFS and Dijkstra's algorithm, including parent-pointer path reconstruction, in `src/query.c`.
- **Entity Indexing:** Built the Binary Search Tree logic (`src/bst.c`) to map entity names to graph nodes efficiently.
